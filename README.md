# E-Commerce Sales Analytics

## 📊 Project Overview

This project analyzes an e-commerce sales dataset using Python, Pandas, and Matplotlib.

The goal is to understand sales, profit, product categories, sub-categories, and yearly performance.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Git & GitHub

## 📁 Dataset

The dataset contains 9,994 e-commerce sales records.

It includes information about:

- Orders
- Customers
- Products
- Categories
- Sales
- Quantity
- Discount
- Profit
- Order and shipping dates

## 🔍 Analysis Performed

The project includes:

- Data type checking
- Missing value analysis
- Basic statistical analysis
- Sales and profit by category
- Sales and profit by sub-category
- Sales and profit by year
- Data visualization using Matplotlib

## 📈 Visualizations

The project includes charts for:

1. Sales and Profit by Category
2. Sales by Year
3. Profit by Sub-Category
